# TiO — Setup & Running Guide

Follow these steps to get your **Context-Aware Chatbot Builder** up and running.

## 1. Prerequisites
Ensure you have the following installed on your system:
- **Python 3.10+**: [Download here](https://www.python.org/downloads/)
- **Node.js 18+**: [Download here](https://nodejs.org/)
- **Ollama**: [Download here](https://ollama.com/)
  - Once installed, open your terminal and run: `ollama run llama3` (this ensures the model is downloaded and ready).

---

## 2. One-Click Setup (Windows)
If you are on Windows, you can simply run the provided `start.bat` file.
1. Double-click `start.bat` in the root directory.
2. Wait for it to install Python dependencies, build the React frontend, and start the server.
3. Access the app at: `http://localhost:8000`

---

## 3. Manual Step-by-Step Setup

### Step A: Environment Configuration
Create a `.env` file in the root directory (one is provided as a template). Ensure your LLM settings match your local Ollama setup:
```env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3
```

### Step B: Backend Dependencies
In the root directory, install the required Python libraries:
```bash
pip install -r requirements.txt
```

### Step C: Frontend Build (From the root directory)
TiO serves the frontend directly from the backend. You must build it first:
```bash
cd frontend
npm install
npm run build
cd ..
```

### Step D: Run the Application
Start the main entry point:
```bash
python main.py
```

---

## 4. Using TiO
1. **Create Chatbot**: Go to the "New Chatbot" page.
2. **Ingest Knowledge**: Paste a website URL or upload your PDFs/Docs.
3. **Wait for Status**: The status will change to `ready` once ingestion and embedding are complete.
4. **Chat**: Click "Open Chat" to start interacting with your grounding-aware assistant.
5. **Monitor**: Use the Home dashboard to see real-time stats across all your assistants.

## 🚀 Optimization Tips
- **Keep Ollama running**: The app depends on the local Ollama server.
- **Chrome/Edge**: For the best UI experience, use a modern Chromium-based browser.
- **First Run**: The first ingestion might take a moment as the embedding model (`all-MiniLM-L6-v2`) is downloaded.
