⚡ Embeddable Widget

TiO Widget
on Any Site

Drop a single <script> tag onto any HTML page. Your TiO chatbot appears as a floating assistant — no iframes, no cookies, no tracking.

1. Add the widget script to your page

<!-- Place before </body> --> <script src="http://localhost:8888/widget.js" data-chatbot-id="1" data-domain="tourism" data-title="Park Assistant" data-accent="#00C6FF" defer ></script>

2. Or use the React component directly

// In any React component import ChatWidget from './components/ChatWidget'; <ChatWidget chatbotId={1} domain="tourism" title="Park Assistant" apiBase="http://localhost:8888" accentColor="#00C6FF" />
